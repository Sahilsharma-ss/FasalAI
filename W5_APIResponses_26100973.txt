10. AI CHAT (Ask the Gemini-Powered Advisor)
================================================================================

  Endpoint:   POST /api/chat
  Auth:       Required (Bearer token)
  Purpose:    Send a farming/agriculture question to the Gemini AI advisor

  REQUEST:
    POST http://localhost:5000/api/chat
    Authorization: Bearer <JWT_TOKEN>
    Content-Type: application/json

    {
      "message": "What is the best fertilizer for tomato plants?"
    }

  RESPONSE (200 OK):
    {
      "answer": "For tomato plants, a balanced fertilizer with NPK ratio of 10-10-10 is recommended during early growth. Once flowering begins, switch to a phosphorus-rich formula like 5-10-10 to support fruit development..."
    }

  ERROR RESPONSE (400 Bad Request — empty message):
    {
      "message": "A question is required"
    }

  ERROR RESPONSE (429 Too Many Requests — AI rate limit):
    {
      "message": "The AI advisor is temporarily busy. Please wait a minute and try again."
    }

  ERROR RESPONSE (500 Internal Server Error):
    {
      "message": "Something went wrong with the AI advisor. Please try again later."
    }

================================================================================
  DATABASE MODELS (MongoDB / Mongoose)
================================================================================

  User Schema:
    - name       : String (required, trimmed)
    - email      : String (required, unique, lowercase, trimmed)
    - password   : String (required, min 6 chars, hashed with bcrypt, hidden)
    - timestamps : createdAt, updatedAt (auto-generated)

  Detection Schema:
    - user       : ObjectId → ref "User" (required, indexed)
    - crop       : String (default "Unknown")
    - disease    : String (required)
    - confidence : Number (required)
    - healthy    : Boolean (default false)
    - advisory   : { summary: String, treatment: [String], prevention: [String] }
    - timestamps : createdAt, updatedAt (auto-generated)
